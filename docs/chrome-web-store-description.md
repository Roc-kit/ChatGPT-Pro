# ChatGPT Pro: The Ultimate AI Toolbox for ChatGPT

ChatGPT Pro 是一个用于 ChatGPT Web 的第三方 Chrome 扩展工具箱，帮助你更方便地查找、筛选、整理和导出历史聊天。

主要功能：

- 悬浮聊天目录：按创建时间查看、排序并打开历史聊天。
- 标题筛选：通过聊天目录表头中的下拉搜索快速过滤对话标题。
- 项目 / GPT 筛选：区分普通聊天、ChatGPT 项目和自定义 GPT，并显示实际名称。
- 原生侧边栏时间：可选在 ChatGPT 左侧聊天列表中显示创建时间。
- 消息时间戳：可选显示用户消息与 ChatGPT 回复的发送时间。
- Markdown 导出：页面右侧提供可上下拖动的导出图标，一键导出当前完整对话，并记忆按钮位置。
- JSON 原始数据导出：可保留 ChatGPT conversation API 返回的原始对话对象及相关元信息。
- 批量导出：在聊天目录中勾选多个对话后，可按限流策略批量导出 Markdown / JSON，并合并打包为 ZIP。
- 本地缓存：聊天目录缓存在浏览器本地，打开目录时优先读取本地数据，再进行增量更新。
- 可配置交互：可设置后台新标签页打开、点击弹窗外部关闭等行为。

隐私说明：

扩展不会把聊天内容、聊天目录或身份验证信息发送到开发者控制的服务器。相关数据仅用于实现扩展功能，目录缓存和设置保存在用户浏览器本地。只有用户主动执行导出时，扩展才会在浏览器本地生成 Markdown、JSON 或 ZIP 文件并交由浏览器下载。
