**好的，排除时间戳后，以下是当前（2025-2026）用户对 ChatGPT 网页版最强烈、最频繁的其他需求。**

这些需求主要来自 OpenAI 官方社区 Feature Request、现有热门扩展的用户反馈，以及实际使用中的痛点。很多已经被主流扩展部分实现，但仍有空白或可做得更好的空间。

### 1. 对话组织与管理（最高优先级、需求量最大）
用户抱怨侧边栏变成“一坨乱麻”，尤其是对话数量上百后几乎无法管理。

**核心需求：**
- **自定义文件夹 + 子文件夹**（独立于官方 Projects）：拖拽移动、颜色标记、折叠/展开、搜索文件夹内对话。
- **标签（Tags）系统**：一个对话可打多个标签，支持智能标签（自动分类）。
- **置顶 / 收藏 / 书签**：重要对话或单条消息可置顶。
- **批量操作**：批量移动、归档、删除、导出。
- **对话笔记**：给对话或文件夹加私人备注（悬停显示）。
- **Projects 内嵌套文件夹**：官方 Projects 目前层级太浅，用户想要更深层组织。

现有扩展（Superpower、AI Toolbox、GPT Master 等）已经在做，但仍有用户觉得不够原生、不够稳定，或免费版限制太多。

### 2. 强大搜索功能
官方搜索只能搜标题，内容搜索极弱。

**需求：**
- 全文字搜索（搜索所有历史消息内容）。
- 高级过滤：按日期范围、角色（用户/AI）、文件夹、标签、关键词精确匹配。
- 搜索结果直接跳转到对应消息位置。
- 跨对话搜索（“找所有关于XX的讨论”）。

### 3. 长对话导航与阅读体验
长对话（几十到几百轮）滚动和定位非常痛苦。

**需求：**
- **Minimap / 大纲导航**：右侧或侧边显示对话结构缩略图，点击跳转。
- **消息书签 / 高亮**：标记重要段落，支持多颜色，统一“我的高亮库”。
- **对话树状图（Tree Map）**：显示分支对话结构（尤其有“Branch in new chat”后很需要）。
- **快速跳转**：跳到顶部/底部、上一轮/下一轮、特定日期。
- **折叠长回复**：可折叠 AI 回复，减少滚动。

### 4. 导出与归档
官方导出功能简陋（尤其不带时间、格式差）。

**需求：**
- 单对话 / 多对话 / 整个文件夹一键导出。
- 支持格式：Markdown（带 YAML 元数据）、PDF、JSON、TXT、DOCX、ZIP。
- 导出时保留格式（代码块、表格、图片、链接）。
- 本地永久归档（即使官方删除也能找回）。
- 批量导出 + 进度显示。

### 5. Prompt 管理
用户每天重复输入相似提示词。

**需求：**
- **Prompt 库**：保存、分类、搜索、一键插入。
- 支持变量（{{变量名}}）。
- **Prompt Chains / 队列**：多步提示自动顺序执行。
- Slash 命令（输入 / 弹出提示库）。
- Prompt 优化器（一键把简单句子变成专业提示）。
- 最近使用 / 收藏提示历史。

### 6. 其他高频体验需求
- **Side Chat / 临时侧边对话**：不污染主对话的临时提问。
- **输入增强**：字数/字符计数、Ctrl+Enter 发送、历史输入上下箭头切换。
- **高亮与笔记系统**：选中文本高亮 + 私人笔记库。
- **UI 自定义**：主题、字体、宽屏模式、紧凑侧边栏、恢复被官方改坏的键盘导航。
- **性能优化**：长对话不卡顿（只渲染可见部分）、减少内存占用。
- **批量删除/归档工具**：官方目前很麻烦。

### 7. 相对空白、机会较大的方向
目前做得较少或做得不够好的：
- **真正跨平台一致的组织系统**（ChatGPT + Claude + Gemini 共用同一套文件夹/标签）。
- **智能自动归档与分类**（基于内容自动建议文件夹/标签）。
- **对话内容级别的引用与引用库**（像学术笔记一样管理关键片段）。
- **离线阅读模式** / 本地知识库。
- **更好的分支对话可视化与管理**。
- **修复官方最近 UI 回归**（键盘导航失效、打印 PDF 坏掉、侧边栏预览过多导致可视对话变少等）。

---

**总结优先级建议（适合做扩展）：**

1. **文件夹 + 标签 + 全文字搜索 + 批量操作**（组织类，竞争激烈但刚需最大）
2. **Minimap + 消息书签/高亮 + 长对话导航**
3. **强大导出系统**
4. **Prompt 库 + Chains**
5. **UI/体验小优化合集**（输入增强、性能、修复官方痛点）

这些需求目前都有现成扩展在覆盖，但市场还很分散，很多用户抱怨“功能重复、不稳定、付费墙太狠、隐私不放心”。如果你做差异化（更轻量、更隐私、更好用、更稳定适配新 UI），机会还是很大的。
